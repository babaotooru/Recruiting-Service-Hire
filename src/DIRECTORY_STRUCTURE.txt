🚀 QUICK START PATHS

To Run:
1. Install Node.js
2. cd hire-camp-recruiting-services
3. npm install
4. npm run dev
5. Open http://localhost:5173

To Edit Programs:
1. Open App.tsx
2. Find programs array (line 8)
3. Edit program objects
4. Save file
5. See changes instantly

To Change WhatsApp:
1. Open components/ProgramCard.tsx
2. Find line ~41
3. Change phone number in: wa.me/919063166195
4. Save file

To Deploy:
1. npm run build
2. Upload dist/ folder
3. Done!
